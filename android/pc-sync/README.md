# Capri Sync v1 — remplacé

Ce petit programme Windows reliait Capri Android 2.0 au PC avant que Capri Desktop sache le faire lui-même. Depuis l'écosystème **2.0.0**, c'est **Capri Link**, intégré à Capri Desktop (menu de Capri > *Capri Link…*), qui relie le téléphone : voir [../../docs/CAPRI-LINK.md](../../docs/CAPRI-LINK.md).

Il reste ici pour mémoire et n'est plus compilé par les workflows. Ne le lance pas en même temps que Capri Desktop 2.0 : les deux utilisent le port 47917.
